# Security policy

**[Türkçe](SECURITY.md) · [English](SECURITY.en.md)**

WhisezOS is experimental software. It is not ready for installation on real
hardware or for use as a security boundary in a production environment.

## Supported versions

Security fixes are applied to the newest commit on the `main` branch. There is
currently no supported stable release; `v0.1.0` is a developer preview only.

## Reporting a vulnerability

Use the private vulnerability-reporting feature on the repository's
**Security** tab:

https://github.com/whisez/WhisezOS/security/advisories/new

Do not publish exploit details in a public issue, discussion, or pull request.

Include the following information in the report:

- Affected component and version/commit
- Steps to reproduce the issue
- Expected security impact
- Suggested mitigation or fix, if available

For a Whisez Guard report, also state whether the issue can execute inspected
content, send data away from the local machine, or cause an unintended file
change.

## Do not share personal information

Do not include passwords, access tokens, personal email addresses, real user
folders, private documents, or entire scanned files. Prepare the smallest
possible anonymized example.
